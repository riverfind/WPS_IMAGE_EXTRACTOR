# WPS Image Extractor

`WPS Image Extractor` 是一个面向 Windows 的桌面工具，用于从 Word/WPS 文档中提取图片，并以缩略图方式进行浏览、筛选、导出、删除和定位。

如果你经常需要从操作手册、配置文档、实施文档中批量整理图片，这个工具可以比手工翻文档更快完成工作。

## 产品亮点

- 批量解析 `.docx` / `.docm` / `.dotx` 文档中的图片
- 缩略图网格浏览，支持大批量图片场景
- 单击预览、双击定位，快速回到文档中的图片位置
- 自动识别重复图片，并支持一键勾选同组重复项
- 支持导出已选图片到指定目录
- 支持删除已选图片，并自动生成备份文件
- 支持过滤已选图片，便于先做视觉清理再处理
- 支持按图片尺寸进行筛选，可按精确值、最小值、最大值过滤
- 支持导出当前已过滤图片的 MD5 列表，便于下次复用过滤规则
- 支持导入 MD5 列表并一键批量过滤当前文档中的匹配图片
- 支持打开“已过滤图片”窗口，集中查看当前被隐藏的图片
- 窗口变窄时自动减列，必要时支持横向滚动

## 适用场景

- 从配置手册中提取截图
- 清理文档中的重复图片
- 批量导出文档插图做归档
- 快速定位某张图片在原文中的位置
- 在删除前先通过缩略图检查和确认目标图片

## 运行环境

- Windows
- Python `3.12`
- 建议安装 WPS Writer 或 Microsoft Word

说明：

- 图片定位功能依赖 WPS/Word 的 COM 自动化能力
- 若未安装 WPS/Word，仍可使用提取、预览、筛选、导出、删除等功能

## 安装与启动

本项目使用 `uv` 管理环境。

安装依赖：

```bash
uv sync
```

启动程序：

```bash
uv run python main.py
```

## 快速上手

1. 点击 `打开 WPS 文档...`
2. 选择要处理的 `.docx` 文档
3. 在中间缩略图区浏览图片
4. 单击缩略图查看预览
5. 勾选需要处理的图片
6. 如需缩小范围，可在左侧输入宽高条件执行尺寸过滤
7. 根据需要执行 `导出所选...`、`过滤所选` 或 `删除所选...`
8. 如果希望复用过滤结果，可执行 `导出过滤MD5...`
9. 下次处理同类文档时，可通过 `导入过滤MD5...` 直接批量过滤

如果删除或外部修改了文档内容，可以点击 `重新加载` 强制刷新当前文档视图。

## 主要功能

### 缩略图浏览

- 以卡片形式展示图片
- 显示文件名、对象序号、分辨率、大小等信息
- 支持搜索文件名 / MD5 / 部件名
- 支持按宽高筛选当前视图中的图片

### 预览与定位

- 单击缩略图：仅预览
- 双击缩略图：尝试在 WPS Writer / Microsoft Word 中定位对应图片

### 重复图处理

- 自动按 MD5 识别重复图片
- 卡片上显示 `重复 N`
- 点击 `重复 N` 可勾选同一重复组的全部图片

### 导出图片

- 支持将当前勾选图片导出到目标目录
- 自动处理重名文件，避免覆盖

### 删除图片

- 删除前提供二次确认
- 删除操作直接写回文档
- 删除前自动生成 `.bak` 备份文件
- 删除后自动重新解析文档

### 视图过滤

- 可将当前勾选图片从缩略图视图中隐藏
- 过滤只影响当前视图，不修改文档内容
- 被过滤隐藏的图片会自动取消勾选，避免误删或误导出
- 支持 `恢复过滤` 一键恢复主视图
- 支持 `查看已过滤...` 打开独立窗口浏览当前已过滤图片

### 尺寸过滤

- 左侧提供尺寸过滤区域，可输入宽和高两个条件
- 支持三种模式：`精确`、`最小`、`最大`
- `精确` 表示宽高都等于输入值
- `最小` 表示宽高都大于等于输入值
- `最大` 表示宽高都小于等于输入值
- 宽或高输入 `*` 时，表示该维度不参与匹配
- 尺寸过滤与文本搜索同时生效，结果取交集

### 过滤规则复用

- 支持将当前已过滤图片的 MD5 去重后导出为文本文件
- 导出格式为 `.txt`，一行一个 MD5
- 支持导入该 MD5 文本文件，并按 MD5 批量过滤当前文档中的匹配图片
- 适合对同一类模板文档重复执行清理

## 界面操作说明

工具栏按钮：

- `打开 WPS 文档...`
- `重新加载`
- `全选`
- `反选`
- `删除所选...`
- `过滤所选`
- `恢复过滤`
- `查看已过滤...`
- `导出过滤MD5...`
- `导入过滤MD5...`
- `导出所选...`

左侧筛选区：

- 搜索文件名 / MD5 / 部件
- 尺寸过滤模式：`精确` / `最小` / `最大`
- 宽、高输入框：支持正整数或 `*`

缩略图区交互：

- 单击缩略图：预览
- 勾选框：选择图片
- 双击缩略图：定位到文档
- 点击 `重复 N`：选择同组重复图片

已过滤图片相关：

- 点击 `查看已过滤...` 可查看当前所有已隐藏图片
- 在已过滤图片窗口中，同样支持单击预览、双击定位
- 点击 `导出过滤MD5...` 可保存当前过滤规则
- 点击 `导入过滤MD5...` 可对当前文档按 MD5 批量过滤

## 小窗口适配

- 缩略图区会根据窗口宽度自动减少列数
- 最小会降到 `1` 列
- 当 `1` 列仍放不下时，会出现横向滚动条
- 支持 `Shift + 鼠标滚轮` 横向滚动

## 注意事项

- 当前主要支持 `.docx` / `.docm` / `.dotx`
- 原生 `.wps` 文件解析尚未完成
- 删除文档图片前，请先关闭 WPS/Word 中已经打开的目标文档
- 图片定位受文档结构和 WPS/Word COM 行为影响，复杂文档中可能存在少量边缘误差
- 文档内可能存在多个外观相同的图片对象，建议结合界面中的对象序号一起判断

## 常见问题

### 删除后界面没有立即对上文档内容怎么办？

- 可直接点击 `重新加载`
- 这会重新解析当前文档，并重建缩略图视图

### 双击定位没有生效怎么办？

- 请先确认本机已安装 WPS Writer 或 Microsoft Word
- 再确认目标文档当前未处于异常占用状态

### 小窗口下看不全怎么办？

- 先缩减列数
- 如果仍看不全，请使用底部横向滚动条

### 过滤规则可以复用到下一次吗？

- 可以
- 先点击 `导出过滤MD5...` 保存当前已过滤图片的 MD5 列表
- 下次打开文档后点击 `导入过滤MD5...` 即可批量应用

### 尺寸过滤怎么用？

- 在左侧选择尺寸过滤模式
- 输入宽和高，例如 `1920 x 1080`
- 如果只想按单个维度过滤，可把另一个输入设为 `*`
- 例如：
  - `精确 + 800 x 600`：只显示 800x600 的图片
  - `最小 + 1000 x *`：显示宽度大于等于 1000 的图片
  - `最大 + * x 300`：显示高度小于等于 300 的图片

## 项目入口

启动入口：

```bash
uv run python main.py
```

GUI 模块结构：

- `app/gui_legacy.py`：重构前的旧 GUI 实现快照，仅保留作对照，不进入当前调用链
- `app/gui/__init__.py`：新的 GUI 公共入口，供 `main.py` 通过 `from app.gui import run` 调用
- `app/gui/app.py`：主窗口壳层、布局装配、启动入口
- `app/gui/actions.py`：文档操作、选择/过滤/导入导出/删除等界面动作
- `app/gui/grid.py`：键盘导航、虚拟缩略图网格、缩略图异步刷新
- `app/gui/dialogs.py`：删除确认窗口、已过滤图片查看窗口
