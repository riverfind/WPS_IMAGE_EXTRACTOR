# WPS Image Extractor

`WPS Image Extractor`（打包版可执行文件名为 `WIE.exe`）是一个面向 Windows 的桌面工具，用于从 Word/WPS 文档中提取图片，并以缩略图方式进行浏览、筛选、导出、删除和定位。

如果你经常需要从操作手册、配置文档、实施文档里批量整理截图，这个工具可以帮你把“翻文档找图、筛图、导图、删图”的过程尽量收敛到一个窗口里完成。

它更适合这几类用户：

- 需要从 `.docx` 文档中批量导出截图或插图的人
- 需要清理文档里重复图片、无用图片的人
- 想先看缩略图再决定删除/导出，避免误操作的人
- 需要快速回到图片在原文位置继续核对的人

## 产品亮点

- 批量解析 `.docx` / `.docm` / `.dotx` 文档中的图片
- 缩略图网格浏览，支持大批量图片场景
- 单击预览、双击定位，快速回到文档中的图片位置
- 预览栏双击或 `O` 键可单开图片查看器，支持滚轮缩放与 `Esc` 关闭
- 自动识别重复图片，并支持一键勾选同组重复项
- 支持导出已选图片到指定目录
- 支持删除已选图片，并自动生成备份文件
- 支持过滤已选图片，便于先做视觉清理再处理
- 支持按图片尺寸进行筛选，可按精确值、最小值、最大值过滤
- 支持导出当前已过滤图片的 MD5 列表，便于下次复用过滤规则
- 支持导入 MD5 列表并一键批量过滤当前文档中的匹配图片
- 支持打开“已过滤图片”窗口，集中查看当前被隐藏的图片
- 窗口变窄时自动减列，必要时支持横向滚动
- 支持方向键 / `HJKL` / `PageUp` / `PageDown` / `Enter` / `Space` 键盘操作
- 支持监听文档外部变更并自动重载，尽量保留当前筛选与预览状态

## 适用场景

- 从配置手册中提取截图
- 清理文档中的重复图片
- 批量导出文档插图做归档
- 快速定位某张图片在原文中的位置
- 在删除前先通过缩略图检查和确认目标图片

## 运行环境

- Windows
- Python `3.12`
- 建议安装 WPS Writer 或 Microsoft Word

说明：

- 图片定位功能依赖 WPS/Word 的 COM 自动化能力
- 若未安装 WPS/Word，仍可使用提取、预览、筛选、导出、删除等功能

## 直接使用

如果你拿到的是打包产物，直接运行：

- `dist/nuitka/main.dist/WIE.exe`

使用前建议：

- 如果你需要“双击定位到文档中的图片”，请先安装 WPS Writer 或 Microsoft Word
- 如果你只需要提取、预览、筛选、导出、删除图片，没有安装 WPS/Word 也可以使用

## 从源码运行

本项目使用 `uv` 管理环境。

安装依赖：

```bash
uv sync
```

启动程序：

```bash
uv run python main.py
```

## 打包为 exe

Nuitka 作为构建工具使用，按当前项目约定建议通过 `uv pip install` 安装开发依赖：

```bash
uv pip install nuitka ordered-set zstandard
```

项目已提供 Windows 打包脚本：

```powershell
.\scripts\build_nuitka.ps1
```

脚本等价于执行以下核心命令：

```bash
uv run python -m nuitka --standalone --windows-console-mode=disable --output-filename=WIE.exe --output-dir=dist/nuitka --assume-yes-for-downloads --enable-plugin=tk-inter --include-package=app --follow-imports --remove-output main.py
```

打包结果默认输出到：

- `dist/nuitka/main.dist/`
- 可执行文件位于 `dist/nuitka/main.dist/WIE.exe`

说明：

- 当前打包目标是 Windows 单目录版本，不是单文件 exe
- 打包后默认隐藏控制台窗口，更适合桌面 GUI 应用分发
- 若首次构建较慢，通常是 Nuitka 在准备编译工具链或下载依赖
- 若项目路径包含中文或其他非 ASCII 字符，脚本会先在系统临时目录中进行中转构建，再把产物复制回 `dist/nuitka`

## 快速上手

1. 点击 `打开 WPS 文档...`
2. 选择要处理的 `.docx` 文档
3. 在中间缩略图区快速浏览文档里的所有图片
4. 单击缩略图只更新右侧预览栏，不会直接勾选
5. 需要处理哪些图片，请用卡片上的复选框勾选
6. 如需查看大图，可双击右侧预览栏，或按 `O` 键单开图片查看器
7. 如需回到原文位置，可双击缩略图，或用键盘选中后按 `Enter`
8. 如需缩小范围，可先用左侧搜索或尺寸过滤把候选图片收窄
9. 根据需要执行 `导出所选...`、`过滤所选` 或 `删除所选...`
10. 如果这批过滤规则下次还要继续用，可执行 `导出过滤MD5...`
11. 下次处理同类文档时，可通过 `导入过滤MD5...` 直接批量过滤

如果当前文档被外部修改并保存，程序会自动检测并重载；如需主动强制刷新，也可以点击 `重新加载`。

## 主要功能

### 缩略图浏览

- 以卡片形式展示图片
- 显示文件名、对象序号、分辨率、大小等信息
- 支持搜索文件名 / MD5 / 部件名
- 支持按宽高筛选当前视图中的图片

### 预览与定位

- 单击缩略图：仅预览
- 双击缩略图：尝试在 WPS Writer / Microsoft Word 中定位对应图片
- 双击右侧预览栏：单开图片查看器
- 图片查看器打开时会尽量让整张图完整显示，并在完整显示的前提下尽可能放大
- 图片查看器支持鼠标滚轮缩放
- 图片查看器支持 `Esc` 关闭

### 重复图处理

- 自动按 MD5 识别重复图片
- 卡片上显示 `重复 N`
- 点击 `重复 N` 可勾选同一重复组的全部图片

### 导出图片

- 支持将当前勾选图片导出到目标目录
- 自动处理重名文件，避免覆盖

### 删除图片

- 删除前提供二次确认
- 删除操作直接写回文档
- 删除前自动生成 `.bak` 备份文件
- 删除后自动重新解析文档

### 视图过滤

- 可将当前勾选图片从缩略图视图中隐藏
- 过滤只影响当前视图，不修改文档内容
- 被过滤隐藏的图片会自动取消勾选，避免误删或误导出
- 支持 `恢复过滤` 一键恢复主视图
- 支持 `查看已过滤...` 打开独立窗口浏览当前已过滤图片

### 尺寸过滤

- 左侧提供尺寸过滤区域，可输入宽和高两个条件
- 支持三种模式：`精确`、`最小`、`最大`
- `精确` 表示宽高都等于输入值
- `最小` 表示宽高都大于等于输入值
- `最大` 表示宽高都小于等于输入值
- 宽或高输入 `*` 时，表示该维度不参与匹配
- 尺寸过滤与文本搜索同时生效，结果取交集

### 过滤规则复用

- 支持将当前已过滤图片的 MD5 去重后导出为文本文件
- 导出格式为 `.txt`，一行一个 MD5
- 支持导入该 MD5 文本文件，并按 MD5 批量过滤当前文档中的匹配图片
- 适合对同一类模板文档重复执行清理

### 自动重载

- 程序会轮询检测当前打开文档的外部变更
- 检测到文档被外部修改并保存后，会自动重新解析当前文档
- 自动重载会尽量保留搜索词、尺寸过滤、已过滤状态、勾选状态和当前预览图片
- 自动重载完成后只在状态栏提示，不会弹窗打断操作

## 界面操作说明

工具栏按钮：

- `打开 WPS 文档...`
- `重新加载`
- `全选`
- `反选`
- `删除所选...`
- `过滤所选`
- `恢复过滤`
- `查看已过滤...`
- `导出过滤MD5...`
- `导入过滤MD5...`
- `导出所选...`

左侧筛选区：

- 搜索文件名 / MD5 / 部件
- 尺寸过滤模式：`精确` / `最小` / `最大`
- 宽、高输入框：支持正整数或 `*`

缩略图区交互：

- 单击缩略图：预览
- 勾选框：选择图片
- 双击缩略图：定位到文档
- 点击 `重复 N`：选择同组重复图片

预览栏与查看器：

- 双击右侧预览栏：打开独立图片查看器
- 查看器内滚轮：放大 / 缩小
- 查看器内 `Esc`：关闭查看器
- 查看器打开时会尽量完整显示当前图片，并在窗口内尽量放大

键盘操作：

- 方向键：移动当前缩略图焦点
- `H J K L`：Vim 式左 / 下 / 上 / 右移动
- `PageUp` / `PageDown`：按页跳转
- `Enter`：定位当前图片到文档
- `Space`：勾选 / 取消勾选当前图片
- `O`：单开当前图片查看器

重载逻辑：

- 点击 `重新加载`：主动重新解析当前文档
- 外部修改并保存当前文档：程序会自动重载
- 自动重载后会尽量恢复当前搜索、过滤、勾选和预览状态

已过滤图片相关：

- 点击 `查看已过滤...` 可查看当前所有已隐藏图片
- 在已过滤图片窗口中，同样支持单击预览、双击定位
- 点击 `导出过滤MD5...` 可保存当前过滤规则
- 点击 `导入过滤MD5...` 可对当前文档按 MD5 批量过滤

## 小窗口适配

- 缩略图区会根据窗口宽度自动减少列数
- 最小会降到 `1` 列
- 当 `1` 列仍放不下时，会出现横向滚动条
- 支持 `Shift + 鼠标滚轮` 横向滚动

## 注意事项

- 当前主要支持 `.docx` / `.docm` / `.dotx`
- 原生 `.wps` 文件解析尚未完成
- 删除文档图片前，请先关闭 WPS/Word 中已经打开的目标文档
- 图片定位受文档结构和 WPS/Word COM 行为影响，复杂文档中可能存在少量边缘误差
- 文档内可能存在多个外观相同的图片对象，建议结合界面中的对象序号一起判断

## 常见问题

### 删除后界面没有立即对上文档内容怎么办？

- 程序现在会自动监听当前文档的外部变更并尝试自动重载
- 如果你希望立即强制刷新，也可以手动点击 `重新加载`
- 若文档正被其他程序占用写入，等保存完成后再观察是否已自动刷新

### 双击定位没有生效怎么办？

- 请先确认本机已安装 WPS Writer 或 Microsoft Word
- 再确认目标文档当前未处于异常占用状态

### 打包后的 exe 启动失败怎么办？

- 先确认是否使用了 `scripts/build_nuitka.ps1` 或 README 中给出的 Nuitka 参数
- 再确认构建环境中 `nuitka`、`ordered-set`、`zstandard` 已安装
- 如果问题与定位功能有关，请优先检查本机的 WPS/Word 与 pywin32/COM 环境
- 若被安全软件拦截，请先将构建目录加入信任或在隔离环境中重试

### 小窗口下看不全怎么办？

- 先缩减列数
- 如果仍看不全，请使用底部横向滚动条

### 图片查看器怎么操作？

- 双击右侧预览栏，或按 `O` 键打开查看器
- 查看器会在打开时尽量完整显示整张图，并在窗口内尽量放大
- 鼠标滚轮可继续放大 / 缩小
- 按 `Esc` 可快速关闭查看器

### 过滤规则可以复用到下一次吗？

- 可以
- 先点击 `导出过滤MD5...` 保存当前已过滤图片的 MD5 列表
- 下次打开文档后点击 `导入过滤MD5...` 即可批量应用

### 尺寸过滤怎么用？

- 在左侧选择尺寸过滤模式
- 输入宽和高，例如 `1920 x 1080`
- 如果只想按单个维度过滤，可把另一个输入设为 `*`
- 例如：
  - `精确 + 800 x 600`：只显示 800x600 的图片
  - `最小 + 1000 x *`：显示宽度大于等于 1000 的图片
  - `最大 + * x 300`：显示高度小于等于 300 的图片

## 项目入口

启动入口：

```bash
uv run python main.py
```

GUI 模块结构：

- `app/gui_legacy.py`：重构前的旧 GUI 实现快照，仅保留作对照，不进入当前调用链
- `app/gui/__init__.py`：新的 GUI 公共入口，供 `main.py` 通过 `from app.gui import run` 调用
- `app/gui/app.py`：主窗口壳层、布局装配、启动入口
- `app/gui/actions.py`：文档操作、选择/过滤/导入导出/删除等界面动作
- `app/gui/grid.py`：键盘导航、虚拟缩略图网格、缩略图异步刷新
- `app/gui/dialogs.py`：删除确认窗口、已过滤图片查看窗口

文档适配器结构：

- `app/docx_adapter_legacy.py`：拆分前的旧单文件适配器实现快照，仅保留作对照
- `app/docx_adapter/__init__.py`：适配器公共入口，保持 `from app.docx_adapter import ...` 导入方式不变
- `app/docx_adapter/adapter.py`：`DocxAdapter` 主类，负责提取图片与删除写回
- `app/docx_adapter/xml_ops.py`：OOXML 解析、图片引用遍历、稳定 ID 与文本上下文提取
- `app/docx_adapter/office.py`：WPS/Word COM 自动化定位与打开状态检查
- `app/docx_adapter/errors.py`：错误类型与导航结果对象
- `app/docx_adapter/constants.py`：命名空间常量与 ZIP/XML 路径辅助函数
